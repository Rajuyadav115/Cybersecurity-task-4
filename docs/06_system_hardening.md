# 6. System Hardening

## Objective
Apply defensive controls after the lab assessment.

### Controls
- Apply security patches.
- Disable unused services.
- Configure a firewall to restrict unnecessary traffic.
- Review exposed ports.
- Remove/default-change weak credentials.
- Use least privilege.
- Enable appropriate logging and monitoring.

## Verification
After changes:
1. Recheck the authorized host.
2. Compare open services before and after hardening.
3. Record the changes.
4. Confirm required services still work.
