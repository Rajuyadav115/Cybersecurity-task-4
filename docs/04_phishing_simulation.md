# 4. Social Engineering – Simulation Only

## Objective
Create an awareness-focused phishing simulation without collecting real credentials.

## Safe Simulation Design
- Use a local/mock page.
- Clearly mark the exercise as a training simulation in the project documentation.
- Do not send deceptive messages to real people without explicit authorization.
- Do not collect, store, or transmit real passwords.
- Use dummy values such as `training-user` and `DEMO_ONLY`.

## Awareness Checks
Participants should learn to identify:
- Suspicious sender/domain
- Unexpected attachments
- Urgent or threatening language
- Suspicious links
- Requests for passwords or MFA codes
- Mismatched URLs
