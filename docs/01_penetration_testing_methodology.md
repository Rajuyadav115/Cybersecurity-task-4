# 1. Penetration Testing Methodology

## Objective
Document every phase of the Task 4 workflow.

### Phase 1 – Reconnaissance
Identify the authorized target, lab network, IP address, and available information.

### Phase 2 – Scanning
Use approved scanning tools to identify open ports and services. Record:
- Target IP
- Date/time
- Scan command used
- Open ports
- Service/version information
- Observations

### Phase 3 – Exploitation
Select a known vulnerability in Metasploitable2 and demonstrate exploitation only inside the isolated lab.

Record:
- Vulnerability/service
- Why it is relevant
- Tool/module used
- Evidence screenshot
- Result
- Mitigation

### Phase 4 – Post-Exploitation
Document the authorized access obtained and collect only the minimum information required for the exercise.

Suggested evidence:
- System information
- Current user/context
- Relevant security observations

### Phase 5 – Reporting
Summarize findings, risk, evidence, root cause, and recommended mitigation.

## Evidence
Add screenshots to `evidence/` and reference them in the final report.
