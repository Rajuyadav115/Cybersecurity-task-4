# Task 4 – Exploitation & System Security

ApexPlanet Cybersecurity & Ethical Hacking Internship

## Objective
Learn and document a responsible penetration-testing workflow in an isolated lab:
Recon → Scanning → Exploitation → Post-Exploitation → Reporting.

## Lab Scope
- Attacker: Kali Linux
- Target: Metasploitable2
- Network: Private/Host-Only lab network
- All testing must be performed only on systems you own or are explicitly authorized to test.

## Repository Structure
- `docs/` – methodology, exploitation notes, password-attack notes, phishing simulation, malware basics, hardening and final report
- `evidence/` – placeholder for screenshots and tool outputs
- `scripts/` – defensive/hardening helper scripts
- `reports/` – final report template
- `checklists/` – execution and evidence checklist

## Important
This repository is a coursework template. Replace the evidence placeholders with your own screenshots and outputs from your authorized lab. Do not test these techniques against public or third-party systems.
